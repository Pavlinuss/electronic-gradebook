# Клиент электронного дневника (лабораторная работа №4)

React-приложение (Vite) для управления списком оценок: добавление, редактирование,
удаление, фильтрация по ученику/предмету, фильтр по семестру, сортировка,
автосохранение в localStorage и статистика по журналу.

## Запуск

Требуется Node.js 22+.

```powershell
cd client
npm install
npm run dev
```

Приложение откроется по адресу http://localhost:5173.

## Тесты

```powershell
npm test
```

Проверяются утилиты: валидация записей, разбор данных из localStorage,
фильтрация, сортировка и статистика.

## Структура

```
client/
  index.html
  vite.config.js
  src/
    main.jsx                     точка входа
    App.jsx                      состояние приложения, эффекты, действия
    hooks/usePersistentGrades.js хук: localStorage + debounce-автосохранение
    components/
      GradeForm.jsx              контролируемая форма добавления/редактирования
      GradeFilters.jsx           поиск, семестр, сортировка
      GradeList.jsx              таблица записей и скелетон загрузки
      Stats.jsx                  статистика: средний балл, количество, семестры
    data/seedGrades.js           начальные демонстрационные данные
    utils/grades.js              валидация, фильтрация, сортировка, формат
  test/grades.test.js            тесты утилит
```

## Возможности

- **CRUD**: добавление, редактирование и удаление оценок (удаление с подтверждением).
- **Фильтрация**: поиск по ученику и предмету, отбор по семестру.
- **Сортировка**: по дате и по значению оценки в обоих направлениях.
- **localStorage**: список сохраняется автоматически через 500 мс после последнего
  изменения; при открытии данные загружаются с валидацией повреждённых записей.
- **Дополнительные эффекты**: заголовок вкладки показывает количество оценок,
  при старте имитируется загрузка с сервера (скелетон), статус сохранения
  отображается в шапке.
- **Горячая клавиша**: Enter в любом поле формы сохраняет запись.

Данные хранятся только в браузере (localStorage), серверная часть не используется —
это требование лабораторной работы №4.
