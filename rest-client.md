# REST Client в VS Code

В проекте уже подготовлен файл `requests.http` с готовыми HTTP-запросами.

1. Откройте проект в VS Code.
2. Установите рекомендуемое расширение **REST Client** (`humao.rest-client`). VS Code предложит установить его автоматически на основании файла `.vscode/extensions.json`.
3. Запустите сервер командой:

```powershell
npm run dev
```

4. Откройте файл `requests.http`.
5. Нажмите **Send Request** над нужным запросом.
6. Ответ откроется в отдельной вкладке VS Code.

Запрос создания записи помечен именем `createGrade`. После его выполнения остальные запросы автоматически используют ID созданной записи:

```http
GET {{baseUrl}}/grades/{{createGrade.response.body.$.id}}
```

Запросы рекомендуется выполнять в таком порядке:

- получение списка;
- создание записи;
- получение созданной записи;
- фильтрация;
- полное обновление через PUT;
- удаление;
- повторное удаление для проверки ответа 404.

В файле также есть отдельный корректно оформленный запрос для проверки недопустимой оценки, который возвращает `400`, и запрос повторного удаления, который возвращает `404`. Поврежденный JSON из основного файла убран, чтобы он не ломал выполнение запросов REST Client.
